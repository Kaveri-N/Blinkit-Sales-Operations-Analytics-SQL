# Blinkit Sales & Operations Analytics — SQL

## Project Overview

This project analyzes Blinkit sales and operations data using SQL to identify customer behavior, product performance, sales trends, operational performance, and key business metrics.

## Business Objectives

- Analyze overall sales and business performance
- Identify high-value customers
- Segment customers based on revenue
- Analyze repeat and one-time customers
- Identify top-performing products and categories
- Compare sales channels
- Analyze monthly revenue trends
- Evaluate order status and delivery performance
- Analyze payment method performance

## Key SQL Analysis

- Customer Revenue Contribution
- Customer Segmentation
- Segment-wise Revenue Analysis
- Repeat vs One-time Customer Analysis
- Customer Lifetime Value
- Top Product Performance
- Category Performance
- Sales Channel Performance
- Monthly Sales Trend
- Order Status Analysis
- Delivery Performance
- Payment Method Analysis
- Overall Business KPIs

## Project Outcome

The analysis provides business-focused insights into customer value, revenue contribution, product and category performance, sales channels, operational efficiency, and customer behavior.
